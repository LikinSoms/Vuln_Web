# Northstar Market

Minimal local e-commerce sandbox for practicing web VAPT workflows with Burp Suite.

## Stack

- Node.js
- Express
- SQLite
- Vanilla HTML/CSS/JS

## Run Locally

```powershell
npm install
npm start
```

Open:

```text
http://localhost:3000
```

## Main Lab Areas

- Login authentication flow
- Order invoice lookup
- Cart checkout flow
